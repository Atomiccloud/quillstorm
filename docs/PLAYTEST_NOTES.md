- Regen and quill count feel insufficient by endgame — consider buffing late-game scaling or adding more stacking options

- Noticeable delay/pause after some upgrades — might be chests or level-ups, unclear which triggers it

- Vampirism should have options above common rarity
- Living Bastion should give more HP and add evasion as well
