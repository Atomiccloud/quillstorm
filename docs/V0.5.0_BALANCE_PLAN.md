# v0.5.0 Elemental, Defense & Balance Overhaul

This document describes the balance changes implemented in v0.5.0 to prevent exploits and improve game feel.

**Note:** v0.5.0 also includes elemental effects, defense stats, and new mythic upgrades (originally planned for v0.4.2). See [GAMEPLAY.md](GAMEPLAY.md) for full documentation of those systems.

---

## Shield System Overhaul

### Problem
Players could stack shield upgrades infinitely, and with enough prosperity the iframe duration allowed effective invincibility by regenerating shields faster than they could break.

### Solution

**Hard cap at 10 shield charges** — prevents excessive stacking.

**Diminishing iframes on rapid hits:**
| Hit # | Duration |
|-------|----------|
| 1st | 400ms |
| 2nd | 240ms |
| 3rd | 144ms |
| 4th+ | 100ms (floor) |

Iframe duration resets to 400ms after 2 seconds without shield breaks.

**Restructured shield upgrades:**
| Upgrade | Rarity | Shields | Bonus |
|---------|--------|---------|-------|
| ~~Energy Shield~~ | ~~Uncommon~~ | - | *REMOVED* |
| Reinforced Shield | Rare | +1 | - |
| Fortress | Epic | +2 | +30 HP |
| Immortal Fortress | Legendary | +4 | +100 HP |

Shield upgrades are hidden from the pool when at the 10-charge cap.

## Prosperity System Overhaul

### Problem
Prosperity granted too many benefits at once (chest drops, rarity shift, crit bonus), leading to exponential power scaling at high values.

### Changes

**Crit bonus removed from prosperity** — crit is now purely from upgrades, with its own diminishing returns.

**Logarithmic chest drop curve:**
Formula: `bonus = 0.13 × (1 - e^(-prosperity/161))`

| Prosperity | Old (Linear) | New (Log) |
|------------|-------------|-----------|
| 0 | 1% | 1% |
| 100 | 21% | 7% |
| 200 | 41% | 10.3% |
| 500 | - | 13.4% |
| ∞ | - | 14% (cap) |

**Base Weights:** Common 65%, Uncommon 25%, Rare 6%, Epic 3.5%, Legendary 0.49%, Mythic 0.01%

## Crit Diminishing Returns

**Formula:** `effectiveCrit = rawCrit / (rawCrit + 1)`

| Raw Crit | Effective |
|----------|-----------|
| 25% | 20% |
| 50% | 33% |
| 100% | 50% |
| 200% | 67% |
| 300% | 75% |

Display changed to flat number: "+100 Crit" instead of "+100%"

## Gameplay Caps

### Movement Speed Cap
Maximum speed: 600 px/sec

Prevents gameplay from becoming uncontrollable at extreme speed stacking.

### Explosion Radius Cap
Maximum radius: 400px (covers ~56% width, nearly full height)

Allows large screen presence while preventing infinite stacking.

### Score Submission Cap
Removed the previous 2,999,999 cap to allow legitimate high scores.

## Summary of Changes

| Mechanic | Before | After |
|----------|--------|-------|
| Shield cap | None | 10 charges |
| Shield iframe | 500ms fixed | 400ms→100ms diminishing |
| Shield upgrades | Uncommon→Legendary | Rare→Legendary only |
| Chest drop @ 100 | 21% | 7% |
| Max chest drop | 41% | 14% |
| Crit from prosperity | +40% at 200 | Removed |
| Crit formula | Linear | x/(x+1) diminishing |
| Crit display | "Crit Chance: +100%" | "Crit: +100" |
| Level-up weights | 60/25/10/4/1/0.05 | 65/25/6/3.5/0.49/0.01 |
| Chest weights | 0/45/35/15/5/0 | 0/61/30/8/1/0.01 |
| Movement speed | Unlimited | 600 px/sec cap |
| Explosion radius | Unlimited | 400px cap |
| Score submission | 2.99M cap | Unlimited |
